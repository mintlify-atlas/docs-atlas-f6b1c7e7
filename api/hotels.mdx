---
title: "Hotels API — List, Get, Create, Update, Delete"
description: "Referencia completa para todos los endpoints CRUD de hoteles. Lista hoteles, obtén por ID y gestiona registros de hoteles con operaciones de creación, actualización y eliminación exclusivas para administradores."
---

La Hotels API te permite obtener listados de hoteles y, para usuarios administradores, gestionar registros de hoteles. Todos los datos de hoteles se almacenan con una clave primaria UUID (`idHotel`). Las amenidades se almacenan como un array JSON y se devuelven como un array parseado en cada respuesta.

<Note>
  Los endpoints marcados como **solo admin** requieren un JWT válido con `rol: "admin"`. Pasa el token en el header `Authorization` como `Bearer <token>`.
</Note>

---

## GET /api/hotels

Devuelve todos los hoteles del sistema. No requiere autenticación.

### Respuesta

<ResponseField name="[]" type="object[]">
  Array de objetos hotel.

  <Expandable title="propiedades del objeto hotel">
    <ResponseField name="idHotel" type="string" required>
      UUID que identifica de forma única al hotel.
    </ResponseField>

    <ResponseField name="nombre" type="string" required>
      Nombre del hotel.
    </ResponseField>

    <ResponseField name="description" type="string" required>
      Descripción detallada del hotel.
    </ResponseField>

    <ResponseField name="location" type="string" required>
      Ubicación geográfica del hotel.
    </ResponseField>

    <ResponseField name="image" type="string" required>
      URL de la imagen principal del hotel.
    </ResponseField>

    <ResponseField name="rating" type="number" required>
      Puntuación de valoración del 0 al 5.
    </ResponseField>

    <ResponseField name="amenities" type="string[]" required>
      Lista de amenidades, ej. `["WiFi", "Pool", "Gym"]`.
    </ResponseField>
  </Expandable>
</ResponseField>

### Ejemplo

```bash
curl http://localhost:5000/api/hotels
```

```json
[
  {
    "idHotel": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "nombre": "Hotel Vini Grand",
    "description": "A luxury hotel in the heart of the city.",
    "location": "Downtown, Caracas",
    "image": "https://example.com/images/hotel-vini-grand.jpg",
    "rating": 4.8,
    "amenities": ["WiFi", "Pool", "Gym", "Spa", "Restaurante 24/7"]
  }
]
```

## GET /api/hotels/:idHotel

Devuelve un único hotel por su UUID. No requiere autenticación.

### Parámetros de ruta

<ParamField path="idHotel" type="string" required>
  UUID del hotel a obtener.
</ParamField>

### Respuesta

<ResponseField name="idHotel" type="string" required>
  UUID del hotel.
</ResponseField>

<ResponseField name="nombre" type="string" required>
  Nombre del hotel.
</ResponseField>

<ResponseField name="description" type="string" required>
  Descripción detallada.
</ResponseField>

<ResponseField name="location" type="string" required>
  Ubicación geográfica.
</ResponseField>

<ResponseField name="image" type="string" required>
  URL de la imagen principal del hotel.
</ResponseField>

<ResponseField name="rating" type="number" required>
  Puntuación de valoración del 0 al 5.
</ResponseField>

<ResponseField name="amenities" type="string[]" required>
  Array parseado de amenidades.
</ResponseField>

<ResponseField name="createdAt" type="string" required>
  Timestamp ISO 8601 de cuándo se creó el registro.
</ResponseField>

<ResponseField name="updatedAt" type="string" required>
  Timestamp ISO 8601 de la última actualización.
</ResponseField>

### Ejemplo

```bash
curl http://localhost:5000/api/hotels/a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

```json
{
  "idHotel": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "nombre": "Hotel Vini Grand",
  "description": "A luxury hotel in the heart of the city.",
  "location": "Downtown, Caracas",
  "image": "https://example.com/images/hotel-vini-grand.jpg",
  "rating": 4.8,
  "amenities": ["WiFi", "Pool", "Gym", "Spa", "Restaurante 24/7"],
  "createdAt": "2026-01-15 10:00:00",
  "updatedAt": "2026-04-01 08:30:00"
}
```

<Warning>
  Devuelve `404` con `{ "error": "Hotel no encontrado" }` si no existe ningún hotel con el `idHotel` indicado.
</Warning>

## POST /api/hotels

Crea un nuevo registro de hotel. **Solo admin.**

<Note>
  Requiere `Authorization: Bearer <token>` con un JWT emitido a un usuario con `rol: "admin"`.
</Note>

### Parámetros del body

<ParamField body="nombre" type="string" required>
  Nombre del hotel.
</ParamField>

<ParamField body="description" type="string" required>
  Descripción detallada del hotel.
</ParamField>

<ParamField body="location" type="string" required>
  Ubicación geográfica del hotel.
</ParamField>

<ParamField body="image" type="string" required>
  URL de la imagen principal del hotel.
</ParamField>

<ParamField body="rating" type="number" required>
  Puntuación de valoración del 0 al 5.
</ParamField>

<ParamField body="amenities" type="string[]" required>
  Array JSON de strings de amenidades, ej. `["WiFi", "Pool", "Gym"]`.
</ParamField>

### Respuesta

<ResponseField name="message" type="string" required>
  Mensaje de confirmación: `"Hotel creado exitosamente"`.
</ResponseField>

<ResponseField name="idHotel" type="string" required>
  UUID asignado al hotel recién creado.
</ResponseField>

### Ejemplo

```bash
curl -X POST http://localhost:5000/api/hotels \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <admin_token>" \
  -d '{
    "nombre": "Hotel Vini Grand",
    "description": "A luxury hotel in the heart of the city.",
    "location": "Downtown, Caracas",
    "image": "https://example.com/images/hotel-vini-grand.jpg",
    "rating": 4.8,
    "amenities": ["WiFi", "Pool", "Gym", "Spa"]
  }'
```

```json
{
  "message": "Hotel creado exitosamente",
  "idHotel": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

## PUT /api/hotels/:idHotel

Actualiza un hotel existente. **Solo admin.** Puedes enviar cualquier subconjunto de los campos del hotel.

<Note>
  Requiere `Authorization: Bearer <token>` con un JWT emitido a un usuario con `rol: "admin"`.
</Note>

### Parámetros de ruta

<ParamField path="idHotel" type="string" required>
  UUID del hotel a actualizar.
</ParamField>

### Parámetros del body

<ParamField body="nombre" type="string">
  Nombre actualizado del hotel.
</ParamField>

<ParamField body="description" type="string">
  Descripción actualizada.
</ParamField>

<ParamField body="location" type="string">
  Ubicación geográfica actualizada.
</ParamField>

<ParamField body="image" type="string">
  URL de imagen actualizada.
</ParamField>

<ParamField body="rating" type="number">
  Puntuación de valoración actualizada (0–5).
</ParamField>

<ParamField body="amenities" type="string[]">
  Array de amenidades actualizado.
</ParamField>

### Respuesta

<ResponseField name="message" type="string" required>
  Mensaje de confirmación: `"Hotel actualizado exitosamente"`.
</ResponseField>

### Ejemplo

```bash
curl -X PUT http://localhost:5000/api/hotels/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <admin_token>" \
  -d '{
    "rating": 4.9,
    "amenities": ["WiFi", "Pool", "Gym", "Spa", "Restaurante 24/7", "Servicio de habitaciones"]
  }'
```

```json
{
  "message": "Hotel actualizado exitosamente"
}
```

<Warning>
  Devuelve `404` con `{ "error": "Hotel no encontrado" }` si no existe ningún hotel con el `idHotel` indicado.
</Warning>

## DELETE /api/hotels/:idHotel

Elimina permanentemente un hotel del sistema. **Solo admin.**

<Warning>
  Esta acción es irreversible. Eliminar un hotel también afectará a cualquier habitación asociada. Requiere `Authorization: Bearer <token>` con `rol: "admin"`.
</Warning>

### Parámetros de ruta

<ParamField path="idHotel" type="string" required>
  UUID del hotel a eliminar.
</ParamField>

### Respuesta

<ResponseField name="message" type="string" required>
  Mensaje de confirmación: `"Hotel eliminado exitosamente"`.
</ResponseField>

### Ejemplo

```bash
curl -X DELETE http://localhost:5000/api/hotels/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "Authorization: Bearer <admin_token>"
```

```json
{
  "message": "Hotel eliminado exitosamente"
}
```
