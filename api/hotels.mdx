---
title: "Hotels API — List, Get, Create, Update, Delete"
description: "Full reference for all hotel CRUD endpoints. List hotels, fetch by ID, and manage hotel records with admin-only create, update, and delete operations."
---

The Hotels API lets you retrieve hotel listings and, for admin users, manage hotel records. All hotel data is stored with a UUID primary key (`idHotel`). Amenities are stored as a JSON array and returned as a parsed array in every response.

<Note>
  Endpoints marked **admin only** require a valid JWT with `rol: "admin"`. Pass the token in the `Authorization` header as `Bearer <token>`.
</Note>

---

## GET /api/hotels

Returns every hotel in the system. No authentication required.

### Response

<ResponseField name="[]" type="object[]">
  Array of hotel objects.
  <Expandable title="hotel object properties">
    <ResponseField name="idHotel" type="string" required>
      UUID that uniquely identifies the hotel.
    </ResponseField>
    <ResponseField name="nombre" type="string" required>
      Hotel name.
    </ResponseField>
    <ResponseField name="description" type="string" required>
      Detailed description of the hotel.
    </ResponseField>
    <ResponseField name="location" type="string" required>
      Geographic location of the hotel.
    </ResponseField>
    <ResponseField name="image" type="string" required>
      URL of the hotel's main image.
    </ResponseField>
    <ResponseField name="rating" type="number" required>
      Rating score from 0 to 5.
    </ResponseField>
    <ResponseField name="amenities" type="string[]" required>
      List of amenities, e.g. `["WiFi", "Pool", "Gym"]`.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example

```bash
curl http://localhost:5000/api/hotels
```

```json
[
  {
    "idHotel": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "nombre": "Hotel Vini Grand",
    "description": "A luxury hotel in the heart of the city.",
    "location": "Downtown, Caracas",
    "image": "https://example.com/images/hotel-vini-grand.jpg",
    "rating": 4.8,
    "amenities": ["WiFi", "Pool", "Gym", "Spa", "Restaurante 24/7"]
  }
]
```

## GET /api/hotels/:idHotel

Returns a single hotel by its UUID. No authentication required.

### Path parameters

<ParamField path="idHotel" type="string" required>
  UUID of the hotel to retrieve.
</ParamField>

### Response

<ResponseField name="idHotel" type="string" required>
  UUID of the hotel.
</ResponseField>
<ResponseField name="nombre" type="string" required>
  Hotel name.
</ResponseField>
<ResponseField name="description" type="string" required>
  Detailed description.
</ResponseField>
<ResponseField name="location" type="string" required>
  Geographic location.
</ResponseField>
<ResponseField name="image" type="string" required>
  URL of the hotel's main image.
</ResponseField>
<ResponseField name="rating" type="number" required>
  Rating score from 0 to 5.
</ResponseField>
<ResponseField name="amenities" type="string[]" required>
  Parsed array of amenities.
</ResponseField>
<ResponseField name="createdAt" type="string" required>
  ISO 8601 timestamp of when the record was created.
</ResponseField>
<ResponseField name="updatedAt" type="string" required>
  ISO 8601 timestamp of the last update.
</ResponseField>

### Example

```bash
curl http://localhost:5000/api/hotels/a1b2c3d4-e5f6-7890-abcd-ef1234567890
```

```json
{
  "idHotel": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "nombre": "Hotel Vini Grand",
  "description": "A luxury hotel in the heart of the city.",
  "location": "Downtown, Caracas",
  "image": "https://example.com/images/hotel-vini-grand.jpg",
  "rating": 4.8,
  "amenities": ["WiFi", "Pool", "Gym", "Spa", "Restaurante 24/7"],
  "createdAt": "2026-01-15 10:00:00",
  "updatedAt": "2026-04-01 08:30:00"
}
```

<Warning>
  Returns `404` with `{ "error": "Hotel no encontrado" }` if no hotel exists with the given `idHotel`.
</Warning>

## POST /api/hotels

Creates a new hotel record. **Admin only.**

<Note>
  Requires `Authorization: Bearer <token>` with a JWT issued to a user with `rol: "admin"`.
</Note>

### Body parameters

<ParamField body="nombre" type="string" required>
  Hotel name.
</ParamField>
<ParamField body="description" type="string" required>
  Detailed description of the hotel.
</ParamField>
<ParamField body="location" type="string" required>
  Geographic location of the hotel.
</ParamField>
<ParamField body="image" type="string" required>
  URL of the hotel's main image.
</ParamField>
<ParamField body="rating" type="number" required>
  Rating score from 0 to 5.
</ParamField>
<ParamField body="amenities" type="string[]" required>
  JSON array of amenity strings, e.g. `["WiFi", "Pool", "Gym"]`.
</ParamField>

### Response

<ResponseField name="message" type="string" required>
  Confirmation message: `"Hotel creado exitosamente"`.
</ResponseField>
<ResponseField name="idHotel" type="string" required>
  UUID assigned to the newly created hotel.
</ResponseField>

### Example

```bash
curl -X POST http://localhost:5000/api/hotels \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <admin_token>" \
  -d '{
    "nombre": "Hotel Vini Grand",
    "description": "A luxury hotel in the heart of the city.",
    "location": "Downtown, Caracas",
    "image": "https://example.com/images/hotel-vini-grand.jpg",
    "rating": 4.8,
    "amenities": ["WiFi", "Pool", "Gym", "Spa"]
  }'
```

```json
{
  "message": "Hotel creado exitosamente",
  "idHotel": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

## PUT /api/hotels/:idHotel

Updates an existing hotel. **Admin only.** You may send any subset of the hotel fields.

<Note>
  Requires `Authorization: Bearer <token>` with a JWT issued to a user with `rol: "admin"`.
</Note>

### Path parameters

<ParamField path="idHotel" type="string" required>
  UUID of the hotel to update.
</ParamField>

### Body parameters

<ParamField body="nombre" type="string">
  Updated hotel name.
</ParamField>
<ParamField body="description" type="string">
  Updated description.
</ParamField>
<ParamField body="location" type="string">
  Updated geographic location.
</ParamField>
<ParamField body="image" type="string">
  Updated image URL.
</ParamField>
<ParamField body="rating" type="number">
  Updated rating score (0–5).
</ParamField>
<ParamField body="amenities" type="string[]">
  Updated amenities array.
</ParamField>

### Response

<ResponseField name="message" type="string" required>
  Confirmation message: `"Hotel actualizado exitosamente"`.
</ResponseField>

### Example

```bash
curl -X PUT http://localhost:5000/api/hotels/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <admin_token>" \
  -d '{
    "rating": 4.9,
    "amenities": ["WiFi", "Pool", "Gym", "Spa", "Restaurante 24/7", "Servicio de habitaciones"]
  }'
```

```json
{
  "message": "Hotel actualizado exitosamente"
}
```

<Warning>
  Returns `404` with `{ "error": "Hotel no encontrado" }` if no hotel exists with the given `idHotel`.
</Warning>

## DELETE /api/hotels/:idHotel

Permanently removes a hotel from the system. **Admin only.**

<Warning>
  This action is irreversible. Deleting a hotel will also affect any associated rooms. Requires `Authorization: Bearer <token>` with `rol: "admin"`.
</Warning>

### Path parameters

<ParamField path="idHotel" type="string" required>
  UUID of the hotel to delete.
</ParamField>

### Response

<ResponseField name="message" type="string" required>
  Confirmation message: `"Hotel eliminado exitosamente"`.
</ResponseField>

### Example

```bash
curl -X DELETE http://localhost:5000/api/hotels/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "Authorization: Bearer <admin_token>"
```

```json
{
  "message": "Hotel eliminado exitosamente"
}
```
