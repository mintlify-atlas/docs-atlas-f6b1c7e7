---

La Invoices API gestiona los registros de facturación en ViniHotel. Cada factura está vinculada a una reserva y a un usuario, y contiene un desglose completo del precio incluyendo subtotal, impuestos, total y cualquier cargo adicional como tarifas de resort o estacionamiento. Las facturas se crean después de que una reserva es confirmada y pueden actualizarse a medida que cambia el estado del pago.

<Note>
  Todos los endpoints de facturas requieren un header `Authorization: Bearer <token>` salvo que se indique lo contrario. El token se obtiene desde `/api/auth/login`.
</Note>

---

## GET /api/invoices/my-invoices

Devuelve todas las facturas pertenecientes al usuario autenticado actualmente, combinadas con detalles de habitación y hotel. Requiere autenticación.

El servidor extrae el `userId` del JWT para filtrar los resultados.

### Headers

<ParamField header="Authorization" type="string" required>
  `Bearer <token>` — JWT obtenido al iniciar sesión.
</ParamField>

### Respuesta

<ResponseField name="[]" type="object[]">
  Array de objetos factura del usuario autenticado.

  <Expandable title="propiedades del objeto factura">
    <ResponseField name="id" type="string" required>
      UUID de la factura.
    </ResponseField>

    <ResponseField name="bookingId" type="string" required>
      UUID de la reserva asociada.
    </ResponseField>

    <ResponseField name="userId" type="integer" required>
      ID del usuario propietario de la factura.
    </ResponseField>

    <ResponseField name="subtotal" type="number" required>
      Monto antes de impuestos, en USD.
    </ResponseField>

    <ResponseField name="taxes" type="number" required>
      Monto de impuestos en USD.
    </ResponseField>

    <ResponseField name="total" type="number" required>
      Total final: `subtotal + taxes`, en USD.
    </ResponseField>

    <ResponseField name="additionalCharges" type="object" required>
      Objeto JSON con cargos adicionales, ej. `{ "resort_fee": 15.00, "parking": 10.00 }`. Objeto vacío `{}` si no hay ninguno.
    </ResponseField>

    <ResponseField name="paymentMethod" type="string" required>
      Método de pago utilizado: `credit_card`, `debit-card`, `paypal`, o `twallet`.
    </ResponseField>

    <ResponseField name="paymentStatus" type="string" required>
      Estado del pago: `pending`, `paid`, `failed`, o `refunded`.
    </ResponseField>

    <ResponseField name="issuedDate" type="string" required>
      Timestamp ISO 8601 de cuándo fue emitida la factura.
    </ResponseField>

    <ResponseField name="roomId" type="string">
      UUID de la habitación de la reserva asociada (combinado).
    </ResponseField>

    <ResponseField name="hotelId" type="string">
      UUID del hotel (combinado).
    </ResponseField>

    <ResponseField name="hotelName" type="string">
      Nombre del hotel (combinado).
    </ResponseField>
  </Expandable>
</ResponseField>

### Ejemplo

```bash
curl http://localhost:5000/api/invoices/my-invoices \
  -H "Authorization: Bearer <token>"
```
