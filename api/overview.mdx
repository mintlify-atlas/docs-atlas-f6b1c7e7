El backend de ViniHotel expone una API REST construida con Node.js y Express. Cada endpoint está montado bajo el prefijo `/api/` y se comunica exclusivamente en JSON. En desarrollo el servidor corre en `http://localhost:5000`; todos los ejemplos de esta referencia usan esa URL base.

## URL base

```text
http://localhost:5000
```

Todas las rutas tienen el prefijo `/api/`. La configuración CORS del servidor permite solicitudes desde `http://localhost:5173` (el frontend de Vite) por defecto, controlado mediante la variable de entorno `CORS_ORIGIN`.

## Formato de solicitud y respuesta

Todos los cuerpos de solicitud deben enviarse como JSON con el encabezado `Content-Type: application/json`. Todas las respuestas exitosas devuelven JSON. Las respuestas de error siguen una estructura consistente:

```json
{ "error": "Mensaje de error legible" }
```

## Autenticación

Las rutas protegidas requieren un token JWT Bearer pasado en el encabezado `Authorization`:

```text
Authorization: Bearer <token>
```

Los tokens se emiten al registrarse e iniciar sesión, expiran tras **7 días** y codifican el `userId` y `role` del usuario (`client`, `staff` o `admin`). Consulta la página de [Autenticación](/api/authentication) para la referencia completa de registro, inicio de sesión y uso de tokens.

## Health check

Usa el endpoint de health para verificar que el servidor es alcanzable antes de realizar solicitudes autenticadas.

```bash
curl http://localhost:5000/api/health
# Respuesta: {"status":"Backend running"}
```

<Note>
  El endpoint de health no requiere autenticación y es útil para monitoreo de disponibilidad o para confirmar que tu servidor de desarrollo local inició correctamente.
</Note>
