The ViniHotel backend exposes a REST API built with Node.js and Express. Every endpoint is mounted under the `/api/` prefix and communicates exclusively in JSON. In development the server runs on `http://localhost:5000`; all examples in this reference use that base URL.

## Base URL

```
http://localhost:5000
```

All routes are prefixed with `/api/`. The server's CORS configuration allows requests from `http://localhost:5173` (the Vite frontend) by default, controlled via the `CORS_ORIGIN` environment variable.

## Request and Response Format

All request bodies must be sent as JSON with the `Content-Type: application/json` header. All successful responses return JSON. Error responses follow a consistent shape:

```json
{ "error": "Human-readable error message" }
```

## Authentication

Protected routes require a JWT bearer token passed in the `Authorization` header:

```
Authorization: Bearer <token>
```

Tokens are issued on register and login, expire after **7 days**, and encode the user's `userId` and `role` (`client`, `staff`, or `admin`). See the [Authentication](/api/authentication) page for the full registration, login, and token usage reference.

## Health Check

Use the health endpoint to verify the server is reachable before making authenticated requests.

```bash
curl http://localhost:5000/api/health
# Response: {"status":"Backend running"}
```

<Note>
  The health endpoint requires no authentication and is useful for uptime monitoring or confirming that your local development server started successfully.
</Note>
