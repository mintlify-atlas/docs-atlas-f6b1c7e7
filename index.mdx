## Get started

<Steps>
  <Step title="Start the backend">
    Install dependencies and start the Express API server on port 5000.
    ```bash
    cd backend && npm install && npm run dev
    ```
  </Step>
  <Step title="Start the frontend">
    In a separate terminal, start the React app on port 5173.
    ```bash
    npm install && npm run dev
    ```
  </Step>
  <Step title="Open the app">
    Navigate to [http://localhost:5173](http://localhost:5173) and register an account or sign in with the test credentials.
  </Step>
  <Step title="Make your first booking">
    Browse hotels on the home page, select a room, choose your dates, and confirm your reservation.
  </Step>
</Steps>

<Note>
  The backend must be running before you start the frontend. The React app connects automatically to `http://localhost:5000`.
</Note>
