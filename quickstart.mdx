---
title: "Get Started with ViniHotel"
description: "Set up ViniHotel locally in minutes: install dependencies, configure environment variables, and run the backend and frontend servers."
---

ViniHotel requires two servers running simultaneously — an Express backend on port 5000 and a Vite frontend on port 5173. This guide walks through every step from cloning the repository to logging in with a test account.

## Prerequisites

- **Node.js 16 or later** — check with `node --version`
- **Two terminal windows** — one for the backend, one for the frontend
- The backend must be started before the frontend so the database is ready when the React app loads

## Setup steps

<Steps>
  <Step title="Get the code">
    Clone or download the ViniHotel repository so you have the project root and the `backend/` subdirectory available locally.

    ```bash
    git clone <your-repo-url> ViniHotel
    cd ViniHotel
    ```
  </Step>

  <Step title="Install backend dependencies">
    In your first terminal, navigate to the `backend/` folder and install its Node.js dependencies.

    ```bash
    cd backend
    npm install
    ```
  </Step>

  <Step title="Create the backend .env file">
    The backend reads configuration from a `.env` file in the `backend/` directory. Create it with the following content:

    ```bash
    PORT=5000
    DATABASE_PATH=./data/vinihotel.db
    JWT_SECRET=your_super_secret_jwt_key_change_this
    JWT_EXPIRE=7d
    NODE_ENV=development
    CORS_ORIGIN=http://localhost:5173
    ```

    <Warning>
      Change `JWT_SECRET` to a long, random string before deploying to any non-local environment. Never commit your `.env` file to version control — it is already listed in `.gitignore`.
    </Warning>
  </Step>

  <Step title="Start the backend server">
    Still inside `backend/`, start the development server with nodemon. The SQLite database at `backend/data/vinihotel.db` is created automatically on first run, and sample hotels, rooms, and users are seeded.

    ```bash
    npm run dev
    ```

    You should see output like:

    ```
    ✅ Servidor corriendo en http://localhost:5000
    🔌 CORS habilitado para: http://localhost:5173
    ```
  </Step>

  <Step title="Install frontend dependencies">
    Open a second terminal, navigate to the project root (not `backend/`), and install frontend dependencies.

    ```bash
    npm install
    ```
  </Step>

  <Step title="Start the frontend dev server">
    From the project root, start Vite. It connects to the backend automatically via `src/utils/apiClient.ts`, which points to `http://localhost:5000/api`.

    ```bash
    npm run dev
    ```

    Vite will output a local URL:

    ```
    VITE v6.x.x  ready in Xms
    ➜  Local:   http://localhost:5173/
    ```
  </Step>

  <Step title="Open the app">
    Navigate to `http://localhost:5173` in your browser. You will see the ViniHotel home page with the hotel listing.
  </Step>
</Steps>

</Note>

## Health check

Verify the backend is running correctly with a quick curl request:

```bash
curl http://localhost:5000/api/health
```

Expected response:

```json
{ "status": "Backend running" }
```

You can also test the login endpoint directly:

```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"juan@example.com","contrasena":"password123"}'
```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| `npm install` fails | Run `npm cache clean --force` then retry |
| Port 5000 already in use | Set `PORT=5001` in `backend/.env` |
| CORS error in browser console | Verify `CORS_ORIGIN=http://localhost:5173` in `backend/.env` |
| Database error on startup | Delete `backend/data/vinihotel.db` and restart the backend to recreate it |
| "Invalid token" or auth errors | Clear `localStorage` in DevTools: F12 → Application → Local Storage → delete `token` |
