---
title: "Comenzar con ViniHotel"
description: "Configura ViniHotel localmente en minutos: instala dependencias, configura variables de entorno y ejecuta los servidores backend y frontend."
---

ViniHotel requiere dos servidores ejecutándose simultáneamente — un backend Express en el puerto 5000 y un frontend Vite en el puerto 5173. Esta guía te lleva paso a paso desde clonar el repositorio hasta iniciar sesión con una cuenta de prueba.

## Prerrequisitos

- **Node.js 16 o posterior** — verifica con `node --version`
- **Dos ventanas de terminal** — una para el backend, otra para el frontend
- El backend debe iniciarse antes que el frontend para que la base de datos esté lista cuando la aplicación React cargue

## Pasos de configuración

<Steps>
  <Step title="Obtener el código">
    Clona o descarga el repositorio de ViniHotel para tener la raíz del proyecto y el subdirectorio `backend/` disponibles localmente.

    ```bash
    git clone <your-repo-url> ViniHotel
    cd ViniHotel
    ```
  </Step>
  <Step title="Instalar dependencias del backend">
    En tu primera terminal, navega a la carpeta `backend/` e instala sus dependencias de Node.js.

    ```bash
    cd backend
    npm install
    ```
  </Step>
  <Step title="Crear el archivo .env del backend">
    El backend lee la configuración desde un archivo `.env` en el directorio `backend/`. Créalo con el siguiente contenido:

    ```bash
    PORT=5000
    DATABASE_PATH=./data/vinihotel.db
    JWT_SECRET=your_super_secret_jwt_key_change_this
    JWT_EXPIRE=7d
    NODE_ENV=development
    CORS_ORIGIN=http://localhost:5173
    ```

    <Warning>
      Cambia `JWT_SECRET` por una cadena larga y aleatoria antes de desplegar en cualquier entorno que no sea local. Nunca subas tu archivo `.env` al control de versiones — ya está incluido en `.gitignore`.
    </Warning>
  </Step>
  <Step title="Iniciar el servidor backend">
    Aún dentro de `backend/`, inicia el servidor de desarrollo con nodemon. La base de datos SQLite en `backend/data/vinihotel.db` se crea automáticamente en la primera ejecución, y se cargan datos de ejemplo de hoteles, habitaciones y usuarios.

    ```bash
    npm run dev
    ```

    Deberías ver una salida como:

    ```text
    ✅ Servidor corriendo en http://localhost:5000
    🔌 CORS habilitado para: http://localhost:5173
    ```
  </Step>
  <Step title="Instalar dependencias del frontend">
    Abre una segunda terminal, navega a la raíz del proyecto (no a `backend/`) e instala las dependencias del frontend.

    ```bash
    npm install
    ```
  </Step>
  <Step title="Iniciar el servidor de desarrollo del frontend">
    Desde la raíz del proyecto, inicia Vite. Se conecta automáticamente al backend mediante `src/utils/apiClient.ts`, que apunta a `http://localhost:5000/api`.

    ```bash
    npm run dev
    ```

    Vite mostrará una URL local:

    ```text
    VITE v6.x.x  ready in Xms
    ➜  Local:   http://localhost:5173/
    ```
  </Step>
  <Step title="Abrir la aplicación">
    Navega a `http://localhost:5173` en tu navegador. Verás la página principal de ViniHotel con el listado de hoteles.
  </Step>
</Steps>

## Credenciales de prueba

Los usuarios de ejemplo se crean automáticamente por el backend en el primer inicio. Usa estas cuentas para explorar cada rol sin registrarte.

| Email | Password | Role |
| --- | --- | --- |
| `juan@example.com` | `password123` | `client` |
| `maria@example.com` | `password123` | `client` |
| `admin@example.com` | `admin123` | `admin` |

<Note>
  La cuenta de administrador tiene acceso a todas las páginas incluyendo gestión de personal (`/staff`), gestión de hoteles (`/hotels`), gestión de reservas (`/bookings`), limpieza (`/housekeeping`) y reportes (`/reports`).
</Note>

## Verificación de funcionamiento (Health check)

Verifica que el backend esté funcionando correctamente con una solicitud curl rápida:

```bash
curl http://localhost:5000/api/health
```

Respuesta esperada:

```json
{ "status": "Backend running" }
```

También puedes probar el endpoint de inicio de sesión directamente:

```bash
curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"juan@example.com","contrasena":"password123"}'
```

## Solución de problemas

| Problema | Solución |
| --- | --- |
| `npm install` falla | Ejecuta `npm cache clean --force` y vuelve a intentarlo |
| El puerto 5000 ya está en uso | Establece `PORT=5001` en `backend/.env` |
| Error de CORS en la consola del navegador | Verifica que `CORS_ORIGIN=http://localhost:5173` esté en `backend/.env` |
| Error de base de datos al iniciar | Elimina `backend/data/vinihotel.db` y reinicia el backend para recrearla |
| "Invalid token" o errores de autenticación | Limpia `localStorage` en DevTools: F12 → Application → Local Storage → elimina `token` |
